# Privacy Policy for L.L.E Companion

Effective date: August 6, 2026

L.L.E Companion is a free update companion for L.L.E (Legacy Lockscreen Effects).
It is designed to notify users when a new public L.L.E release is available and
to open the corresponding GitHub release page in the user's browser.

## Data collection and sharing

L.L.E Companion does not collect, store, sell, or share personal data. It does
not use accounts, advertising, analytics, tracking technologies, or advertising
identifiers.

The app reads the installed L.L.E package version locally on the device. This
information is not transmitted to the developer or to any analytics service.

## Network access

To check for updates, the app makes an HTTPS request to a small public version
file hosted on `raw.githubusercontent.com`. When the user chooses to view a
release, the app opens the public L.L.E releases page on GitHub in an external
browser. GitHub may process standard network information, such as an IP address,
according to the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

The app does not send the installed L.L.E version, notification settings, or
other locally stored app state with these requests.

## Data stored on the device

L.L.E Companion stores only functional preferences on the device, including:

- whether update notifications are enabled;
- the time and result of the latest update check;
- the last version for which a notification was shown; and
- temporary state used when returning from the external browser.

This information remains in the app's private storage and is removed when the
app's data is cleared or the app is uninstalled. Android backups are disabled.

## Permissions

The app uses network access to check the public version file and may request the
Android notification permission so it can show optional update notifications.
Notifications can be disabled at any time in the app or in Android settings.

## Children's privacy

L.L.E Companion is not directed to children under 13 and does not knowingly
collect information from children.

## Changes to this policy

This policy may be updated if the app's functionality or data practices change.
The current version will remain available at this URL with its effective date.

## Contact

For privacy questions, open an issue in the
[L.L.E Companion repository](https://github.com/Brazzo978/LLE-Companion/issues).

# L.L.E Companion privacy summary

L.L.E Companion contacts only GitHub over HTTPS to read the static L.L.E version file. When the user chooses to install or update L.L.E, Companion opens the matching official GitHub release in the device browser; it never downloads or installs an APK itself.

It does not require an account and does not contain analytics, advertising, telemetry or crash-reporting SDKs. It does not read wallpapers, screenshots, media, contacts, location or accessibility data. It queries only the exact Android package `com.codex.lle64` to compare its installed version. L.L.E remains a separate application without Internet permission.
